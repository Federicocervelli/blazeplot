# BlazePlot v1.0.0-rc.6

Sixth 1.0 release candidate. A sweep of the open 1.0 issues: rendering correctness, a rewritten WebGL backend, gesture and plugin-contract fixes, a Canvas 2D fallback, and an opt-in shared WebGL context. Install with `npm install blazeplot@rc`, and see the [0.x to 1.0 migration guide](https://github.com/Federicocervelli/blazeplot/blob/v1/docs/migrating-to-1.0.md).

## Breaking changes

- `chart.addHistogram` and the `HistogramSeriesConfig` types are removed so histograms are tree-shakeable. Use `chart.addBar({ dataset: HistogramDataset.from(values, options) })`, or `new HistogramDataset(histogram(...))` for precomputed bins.
- Keyboard pan, zoom and fit moved from core into `interactionsPlugin({ keyboard })` (on by default). `accessibility.keyboard` and `ChartKeyboardOptions` are removed.
- `selectionPlugin` ignores presses with Shift, Alt or Ctrl/Cmd held unless `modifier` is set, so Shift-drag pans instead of selecting. A plain drag no longer both selects and box-zooms (new `ctx.dom.claimPointer`).
- `viewportchange` now carries `source` (`user | follow | fit | api | linked`); new `followxchange` event.
- Dataset inputs with mismatched array lengths throw a `RangeError` instead of truncating. `"envelope"` is removed from `SeriesMode`; unknown modes throw.
- Built-in plugin instances (a11y, annotations, crosshair, flame graph, navigator, selection) throw if installed on a second chart: create one instance per chart.
- Scatter `pointSize` is a CSS-pixel diameter and markers are round. Translucent colors now blend (premultiplied alpha).
- Charts with a title or subtitle reserve a title row, so the plot is 26 px (46 px with subtitle) shorter.
- The non-instanced WebGL fallback paths and the internal buffer pool are removed. `ChartOptions.renderer` accepts `"webgl2"` or a factory; the string `"canvas2d"` is not supported (see below).

## New

- Canvas 2D renderer for environments without WebGL2: `blazeplot/renderers/canvas2d` (`canvas2dRenderer()`, `autoRenderer()`).
- Opt-in shared WebGL context across charts: `blazeplot/renderers/shared` (`sharedRenderer()`), to get past the per-page context limit.
- `series.setStyle()`; default series colors no longer repeat after `removeSeries`.
- Cooperative gestures: `wheelZoom: "modifier"`, `touchPan: "two-finger"`, `gestureHint`. Charts no longer force `touch-action: none`; touch handling is Pointer Events only.
- `axes.*.size: "auto"`, legend `position`, and localizable accessibility/legend strings (`messages`, `locale`).
- Charts work in iframes and popup windows (no global `document`/`window`).

## Fixes

- Y precision: large-offset data no longer renders as a staircase (Y origin shift).
- Dense area series keep peaks (min/max LOD). Line and bar series with `downsample: "none"` no longer truncate past buffer capacity.
- Tick labels stay distinct when zoomed in; time axes show date context.
- Annotations honor log/symlog/custom scales and reversed axes. `chart.screenshot()` includes the legend, rotated axis titles and a fresh frame.
- Navigator overview keeps spikes and series with gaps.
- A throwing event listener no longer breaks other listeners or rendering. Hover no longer emits every frame.

## Performance

- WebGL backend: one stream upload per frame and a VAO per program. `Chart.ts` is split into focused modules and the core Chart chunk is about 11 KB smaller.

## Known limitations

- Real-GPU benchmark numbers (Windows/ANGLE, Canvas 2D, 60 fps with a shared context) and real-device two-finger page scrolling are not yet verified.
