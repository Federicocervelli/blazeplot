# BlazePlot v1.0.0-rc.5

Fifth 1.0 release candidate. A final naming pass over the public API before 1.0, plus a smaller core bundle. Install with `npm install blazeplot@rc`, and see the [0.x to 1.0 migration guide](https://github.com/Federicocervelli/blazeplot/blob/main/docs/migrating-to-1.0.md) (change 10 has the full old-to-new table).

## Breaking changes

- Latest-X follow uses one set of names on `Chart` and on the plugin context (`ctx.viewport`): `followX`, `stopFollowX`, `setFollowXPaused`, `getFollowXState` (were `followLatestX` / `stopFollowingLatestX` / `setXFollowPaused` / `getXFollowState` on `Chart` and `follow` / `stopFollow` / `setFollowPaused` / `getFollowState` on the context). `ChartXFollowState` is now `ChartFollowXState`.
- Renamed: `ChartPointerEventState` → `ChartPointerEvent`, `LODStrategy` → `DownsampleStrategy`, `chartDataToCSV` → `chartDataToCsv`, `LinkedChartsOptions.sharedX` → `syncX`.
- Color options end in `Color`: selection `fillColor` / `strokeColor`; navigator `backgroundColor`, `strokeColor`, `fillColor`, `windowFillColor`, `windowStrokeColor`; crosshair `labelBackgroundColor`.
- Removed from the public `Chart`: `getCamera()`, `getWebGLContext()`, `canvas`, `plotElement`, `xAxisElement`, `yAxisElement`, `y2AxisElement`. Apps use `getViewport` / `setViewport` / `pan` / `zoom` and `screenshot()`; plugins use `ctx.dom`, `ctx.layout`, and `ctx.unstable`. `rootElement` and `theme` stay.

## Performance

- The core Chart chunk is about 3.7 KB smaller (shaders are minified in the library build, layout styles and listener wiring are more compact). Bundle budgets are tightened to the new sizes.

## Docs

- Roadmap refreshed: current status reflects the 1.0 release candidates, and remaining work is listed as additive 1.x items.
