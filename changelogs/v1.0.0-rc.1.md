# BlazePlot v1.0.0-rc.1

First release candidate for 1.0. It freezes the public API surface and adds the stability, testing and CI work needed to trust it. Install with `npm install blazeplot@rc`. Please report problems at https://github.com/Federicocervelli/blazeplot/issues; fixes land on the `v1` branch.

Migrating from 0.x? Read the [0.x to 1.0 migration guide](https://github.com/Federicocervelli/blazeplot/blob/v1/docs/migrating-to-1.0.md).

## Breaking changes

- The root entry no longer exports GPU backend internals: `GpuBackend`, `WebGL2Backend`, `GpuBuffer`, `GpuProgram`, `GpuCapabilities`, `GpuResource`, `BufferSpec`, `AttributeSpec`, `DrawSpec`, `UniformValue`, `ChartBackendFactory` and `ChartBackendFactoryContext`. `isWebGL2Available` and `WebGL2UnavailableError` stay public. `ChartOptions.backendFactory` is now internal.
- `Chart.emitSelect` is typed `SelectionState | null`, and `ChartSelectEvent` is no longer generic.
- `RingBuffer` skips samples with a non-finite X and warns once per buffer; `UniformRingBuffer` ignores a non-finite seed X.

## Added

- `MinMaxY`, `StaticDatasetData` and `ExportableChart` (from `blazeplot/data`) are exported, because public signatures reference them.
- Stability tiers: the plugin contract, dataset fast-path interfaces, camera access and `blazeplot/plugins/flamegraph` are marked `@experimental` (see `docs/stability.md`).
- New docs: stability guarantees, error handling, accessibility, the 0.x to 1.0 migration guide, and framework, SSR and no-WebGL2 fallback guides.
- `CODE_OF_CONDUCT.md`, a root `CHANGELOG.md`, and a shorter `SECURITY.md`.

## Fixed

- `Chart.dispose()` is idempotent, and it releases the WebGL context. Mounting and unmounting charts in a loop could previously exhaust the browser's context limit and make a visible chart lose its context. The flame graph plugin had the same leak.
- After a context restore, the old renderer no longer deletes GL objects from the lost context (WebKit logged `INVALID_OPERATION`).
- With the default `followLive`, the navigator no longer reverts box zoom, pan, `setViewport` or navigator drags.

## Quality and tooling

- Public API snapshot check, Oxlint, coverage floors (about 90% of `src/`), property tests for the core data structures, Chart and plugin lifecycle tests, a real-browser leak and stability suite, Firefox and WebKit smoke tests, pixel baselines, a performance regression gate, and a TypeScript 5.0 floor check.
