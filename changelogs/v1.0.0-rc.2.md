# BlazePlot v1.0.0-rc.2

Second 1.0 release candidate. It finalizes the subpath layout. Install with `npm install blazeplot@rc`, and see the [0.x to 1.0 migration guide](https://github.com/Federicocervelli/blazeplot/blob/v1/docs/migrating-to-1.0.md).

## Breaking changes

- Chart data export moved from `blazeplot/data` to `blazeplot/export`: `exportChartData`, `chartDataToCSV`, `ExportableChart` and the `ChartData*` types. `blazeplot/export` now covers everything that gets data or images out of a chart, and `blazeplot/data` keeps only chart-agnostic transforms (`binSamples`, `rollingMean`).
- `blazeplot/plugins/flamegraph` no longer exports `buildFlameGraphModel` or `pickFrame`. Use the plugin's `foldedStacks` and `build` options, `setFoldedStacks()` and `pick()` instead.
