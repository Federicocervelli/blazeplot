# BlazePlot v1.0.0-rc.3

Third 1.0 release candidate. It stabilizes the plugin contract, validates dataset input, and adds accessibility support. Because the API changed, the release-candidate soak restarts with this version. Install with `npm install blazeplot@rc`, and see the [0.x to 1.0 migration guide](https://github.com/Federicocervelli/blazeplot/blob/v1/docs/migrating-to-1.0.md).

## Breaking changes

- **Stable plugin contract.** `ChartPluginContext` is now grouped into `ctx.coords`, `ctx.viewport`, `ctx.state`, `ctx.layout`, `ctx.dom`, `ctx.events`, `ctx.theme` and `ctx.requestRender()`. Plugins attach DOM with `ctx.dom.mount(slot, el)`, `listen` and `decorate` instead of raw element getters. `getWebGLContext`, `getCamera` and the canvas move under the experimental `ctx.unstable`. The migration guide has the old-to-new mapping.
- `emitSelect` is replaced by typed plugin events: `ctx.events.emit(...)` with a `ChartPluginEventMap` that third-party plugins extend by declaration merging. `Chart.emitSelect` and `Chart.setLayoutReservation` are removed.
- Plugins now dispose in reverse registration order. Plugin handles can implement `onResize`, `onThemeChange`, `onContextLost` and `onContextRestored`.
- The `render` options of the legend, tooltip and crosshair plugins receive the plugin context instead of the `Chart`.
- **One X rule for every dataset:** X must be finite and non-decreasing; a non-finite Y is a gap. `StaticDataset`, `StaticOhlcDataset`, `ServerSampledDataset` and `fromObjects` throw a `RangeError` naming the first bad index. Pass `{ assumeSorted: true }` to skip the check, or use `StaticDataset.sorted(...)` / `StaticOhlcDataset.sorted(...)` to sort and drop non-finite X.
- `RingBuffer.update` returns `false` instead of storing an X outside its neighbors.
- The chart root now has `role="figure"` (was `img`) and is described through `aria-describedby`. `ResolvedChartTheme` has a new required `focusRingColor` token.

## Features

- Streaming buffers (`RingBuffer`, `OhlcRingBuffer`) skip invalid samples, warn once, and expose `rejectedSamples` plus an `onInvalidSample` callback (also on `SeriesConfig`).
- New `blazeplot/plugins/a11y`: a visually hidden data table of the visible data, an opt-in throttled `aria-live` summary for live charts, and a keyboard inspection cursor that drives the tooltip and crosshair.
- Generated chart summary (series, ranges, latest values), overridable with `accessibility.description`; `chart.getSummary()`.
- Keyboard selection (Shift+Arrow, Enter, Escape), focusable annotations (Enter, Delete), and visible focus rings throughout.
- Forced-colors (high contrast) support, and a contrast test for the default themes.
- Plugin context additions: `ctx.state.inspect()`, `ctx.state.getInspection()` and `ctx.coords.format()`.

## Docs and tests

- Rewritten `docs/plugin-authoring.md` with a typechecked third-party plugin example, and rewritten `docs/accessibility.md` with the key map and guarantees.
- axe-core checks and keyboard-only interaction tests in the browser suite; property tests for dataset input validation; a test that keeps built-in plugins on the stable contract.
