# BlazePlot v0.5.3

## Changes

- Fixed wheel zoom, trackpad pan, shift-drag pan, touch pan/pinch, keyboard navigation, and box zoom on the plot area only moving the left Y axis, so series on the right Y axis stayed put (#59). Each Y axis keeps its own scale and direction: zoom and pan are applied relative to each axis around the same screen point, a reversed `y2` is mirrored correctly, and box zoom maps the selected rectangle through each axis separately. Wheel or drag on a single axis gutter still affects only that axis.
- `chart.zoom(intent)` and `chart.pan(intent)` called without a Y axis now move both Y axes, matching `fitToData()`. Pass `"left"` or `"right"` to target one axis.
