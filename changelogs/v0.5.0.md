# BlazePlot v0.5.0

0.5 is a cleanup release: every task now has one API, dead code is gone, and several options that were silently ignored now work. It contains breaking changes; see the [migration table](../docs/versioning-and-migration.md#migrating-to-05) for one-line replacements.

## Changes

- Series styles accept CSS colors (`"#3b82f6"`, `"var(--accent)"`) as well as RGBA tuples.
- `lineWidth` is now honored for lines, area outlines, OHLC ticks, and candlestick wicks; previously every line rendered one device pixel wide.
- Dense lines no longer disappear on flat or low-variance stretches; min/max buckets keep at least `lineWidth` of height.
- `StaticDataset` range min/max queries are logarithmic instead of linear, speeding up dense rendering, scatter culling, and picking on large static datasets. `RingBuffer` uses the same block index and needs about 30× less memory for it.
- `viewportPolicy.beforePan` and `beforeZoom` now apply to every pan and zoom (pointer, wheel, touch, keyboard, and API calls) and returning `null` cancels the change.
- Selection bounds respect log, symlog, and reversed axes.
- Tooltip and crosshair labels render formatter output and series names as text, never HTML.
- `ServerSampledDataset` min/max buckets report their X interval to tooltips, picks, and `fitToData`.
- New theme tokens `selectionFillColor`, `selectionStrokeColor`, `crosshairColor`, and `markerStrokeColor` replace hard-coded overlay colors.
- One typed `chart.subscribe(event, callback)` event map; unknown event names are a type error instead of silently subscribing to `serieschange`.
- `exportChartData(chart, { range })` replaces the three export functions in `blazeplot/data`; `rollingMean` is O(n).
- `createLinkedCharts` takes `panelPlugins(syncGroup)` so linked dashboards bundle only the plugins they use; `blazeplot/linked-core` is gone.
- Removed duplicate entry points `blazeplot/core`, `blazeplot/interaction`, and `blazeplot/render`; everything they exported is available from `blazeplot`.
- Removed deprecated and redundant APIs, including `ReglBackend`, the legacy `series.append(x, y)`/`appendY`/`appendOhlc`/`updateLastOhlc` forms, `resumeXFollow`, `histogramDataset`, `chartDataToJSON`, `CHART_SCREENSHOT_PRESETS`, and internal classes that leaked into the public API.
- The default `import { Chart } from "blazeplot"` graph is about 13% smaller (gzip).
- Published typings no longer expose renderer-internal `SeriesStore` methods.
- CI runs typecheck/unit/package checks and browser suites as parallel jobs on every pull request, including from forks; releases reuse the same CI and keep `development` and `main` on the same commit.
