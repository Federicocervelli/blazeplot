# BlazePlot v1.0.3

## Fixes

- **Min/max pyramid for custom datasets:** a wrapping ring whose oldest X values tie no longer keeps stale extremes. Spikes stay visible in downsampled views.
- **Pyramid precision:** min/max levels are stored as float64, so large-magnitude Y values are exact. This doubles the pyramid's memory.
- **Pyramid at capacity:** datasets that expose `ordinalOffset` keep using the pyramid while full, instead of falling back to raw scans every frame.
- **Log axes:** a domain inside a single decade now gets visible ticks and gridlines.
- **Linear axes:** subnormal and extreme ranges no longer throw from tick formatting, and tick loops are bounded.
- **Navigator:** drags ignore non-primary buttons and other pointers, and claim the pointer like Selection and Interactions do.
- **WebGL2 warm pool:** a parked chart no longer keeps its context-lost listener, and a backend that was lost while parked is dropped on reuse.
- **Context restore:** a failed backend rebuild retries a few times with backoff instead of leaving the chart permanently blank.
- **Server-sampled buckets:** the newest bucket is no longer dropped when alignment produces one extra bucket.
- **Downloads:** the screenshot object URL is revoked after 10 s, so slow browsers can finish the download.
