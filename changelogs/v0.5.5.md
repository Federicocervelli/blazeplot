# BlazePlot v0.5.5

## Fixes

- Zooming no longer throws at the limits of floating-point precision (#91). Deep wheel or drag zoom on a timestamp axis used to throw after about 22 steps, and zooming out on a log axis overflowed to `Infinity` after about 9. Pan and zoom now stop at the limit instead. When a gesture moves both Y axes and either step is rejected, both stay where they were.
- `fitToData()` and `autoFitY` pad log and symlog axes in scale space, so padding no longer pushes a log axis below zero (#91). An axis whose data has no valid domain for its scale, such as zero or negative values on a log axis, is left unchanged.
- A viewport that is invalid for its axis scale no longer stops the render loop (#91). The chart skips drawing, logs `BlazePlot skipped rendering: ...` once, and resumes as soon as the viewport is valid. A continuous render loop also keeps running if a single frame throws.
- A chart or linked layout that fails to start, for example without WebGL2, now removes its DOM and returns a canvas you passed in (#91).
- Selection plugin (#91):
  - Escape only clears the selection of the chart you last pressed or focused in, including charts inside shadow DOM. It does nothing when nothing is selected, and it cancels a drag in progress.
  - The committed rectangle now follows its data through pans, zooms, and resizes.
- Dense line, bar, and scatter series streaming into a full `RingBuffer` no longer shimmer: downsampling buckets stay anchored while old samples are dropped (#92). `UniformRingBuffer` scatter series get the same anchoring.
- CSV exports escape spreadsheet formulas (#92). Text cells such as series ids and names that start with `=`, `+`, `-`, `@`, tab, or carriage return get a leading `'`, so spreadsheet apps show them as text. Numeric cells are unchanged. Pass `escapeFormulas: false` to `chartDataToCSV` for the previous output.

## Changes

- New `valuePrecision: "float64"` option on `RingBuffer`, `UniformRingBuffer`, `OhlcRingBuffer`, `StaticDataset.fromObjects`, and chart-owned series such as `chart.addLine({ capacity, valuePrecision: "float64" })` (#92). Values are stored exactly instead of being rounded to float32, which matters for large prices, counters, or timestamps in tooltips and `chart.pick()`. The default stays `"float32"`.
- `RingBuffer` and `OhlcRingBuffer` log a one-time console warning when X values go backwards (#92), since culling, picking, and range queries assume ascending X.
- New optional `Dataset.ordinalOffset` lets custom streaming datasets keep downsampling buckets stable as they wrap (#92).

## Maintenance

- Pages deploys once per merge from the release workflow, and CI on `main` only runs before publishing; pull requests already pass CI on an up-to-date branch (#88, #90).
