# BlazePlot v1.1.0

## New

- **Graph plugin (experimental):** `blazeplot/plugins/graph` draws nodes and edges on the chart's own engine (WebGL2, Canvas 2D, or the shared context), from small service maps to large networks. It covers:
  - Node shapes, borders, and rings, with content drawn by callbacks.
  - Arrows, dashes, bowed reverse edges, and moving flows.
  - Dragging, keyboard navigation with announcements, picking, and selection.
  - Its own pan and zoom.

  See [Graphs of nodes and edges](https://blazeplot.cervelli.dev/docs/built-in-plugins#graphs-of-nodes-and-edges).
- **Large graphs without sampling:** when 4 000 or more edges share one plain style, the plugin keeps them on the GPU and draws them by level of detail:
  - Edges between nodes with few neighbours, and bridges, come first.
  - What a frame cannot draw as lines is shown as its exact density, fixed to the graph so it holds still while you pan and zoom.
  - Nothing is recomputed while the view moves.

  An 80 000-node, 400 000-edge social network holds 60 frames a second through zooms and drags on a desktop GPU. Pass big edge sets as index arrays (`GraphEdgeArrays`).
- **Dense graphs:** graphs with many edges per node are drawn from a pair decomposition as a density, with detail refined where it can be seen.
- **Render surfaces:** `ctx.unstable.createRenderSurface()` gains `fillShapes`, `strokeSegments`, `fillTriangles`, and `fillField` on every engine. `createSegmentSet` / `drawSegmentSet` keep segments on the engine between frames, so a frame that only pans or zooms them uploads nothing. These are experimental, like the rest of `ctx.unstable`.
- **Previews:** a service map and a 20 000-person social network on the [previews page](https://blazeplot.cervelli.dev/previews).

## Fixes

- **Faint colors:** literal CSS colors keep alpha below 1/255. Chromium's computed style rounded values like `rgba(…, 0.0007)` to fully transparent.

## Size

- The chart-only import graph grows by about 25 KB minified for the new render-surface primitives, because the engines ship in the root graph. The graph plugin is its own subpath (136 KB minified, 40 KB gzipped).
