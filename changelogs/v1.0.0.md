# BlazePlot v1.0.0

The first stable release. BlazePlot is a fast charting library for dense and live time series: GPU-accelerated rendering with an automatic Canvas 2D fallback, ring-buffer streaming, min/max level of detail that stays correct at 10M points, and an optional, tree-shakeable plugin set. The public API is now covered by [semantic versioning](https://github.com/Federicocervelli/blazeplot/blob/main/docs/versioning-and-migration.md#semver-policy) and the [stability tiers](https://github.com/Federicocervelli/blazeplot/blob/main/docs/stability.md).

```bash
npm install blazeplot
```

Upgrading from 0.x? Read the [0.x to 1.0 migration guide](https://github.com/Federicocervelli/blazeplot/blob/main/docs/migrating-to-1.0.md): it lists every breaking change with before and after code and ends with an upgrade checklist. The nine release candidates (`1.0.0-rc.1` to `rc.9`) have their own notes in [`changelogs/`](https://github.com/Federicocervelli/blazeplot/tree/main/changelogs).

## What 1.0 is

- **The rendering engine is an option.** `renderer: "auto" | "webgl2" | "canvas2d" | "shared"`, with identical APIs, plugins, screenshots and export on every engine. `auto` (the default) uses WebGL2 and falls back to Canvas 2D; `shared` puts many charts on one WebGL context; `chart.rendererInfo` reports what is drawing and why.
- **Fast where it counts.** Against uPlot and Chart.js on a fair, 18-scenario suite (real GPU, 7 fresh-page runs per cell), BlazePlot leads sustained pan, streaming, area, scatter, bar, multi-series and 10M-point scenarios, and Canvas 2D beats uPlot on 1M pan, multi-series and bars. Known gaps against uPlot: first-frame time at small sizes (the WebGL context round trip), hover latency, and 50-chart destroy time. See [`benchmarks/latest.md`](https://github.com/Federicocervelli/blazeplot/blob/main/benchmarks/latest.md).
- **Correct at scale.** Min/max LOD keeps spikes visible, large-offset Y data renders without float32 staircase artifacts, translucent colours blend, and exact `downsample: "none"` series draw without truncation.
- **Live data done properly.** `RingBuffer` and `UniformRingBuffer` streaming, latest-X follow that pauses on user pan, and linked charts that share viewports without fighting each other.
- **Plugins.** A stable plugin contract (`ctx.coords`, `viewport`, `state`, `layout`, `dom`, `events`) and optional entry points: interactions, tooltip, crosshair, legend, annotations, selection, navigator, accessibility, and flame graph.
- **Accessible by default.** A labelled figure with a generated data summary, keyboard inspection and selection, forced-colors support, localizable strings, and charts that do not trap page scrolling on touch.
- **Typed.** Series configs are a discriminated union, so wrong combinations fail at compile time; shorthands like `chart.addLine({ x, y })` and `chart.addBar({ values, binCount })` cover the common cases.
- **Well-structured and tested.** A layered, cycle-free source tree enforced in CI, a public API snapshot, typechecked documentation snippets, a Canvas 2D / WebGL2 / shared behavior contract suite, cross-engine visual parity, real-browser stability, leak, accessibility and forced-colors suites, and Firefox and WebKit smoke tests.

## Changes since 1.0.0-rc.9

- The crosshair and synced tooltips no longer appear while a finger scrolls the page: touch moves are ignored unless a long press is active.
- Touch long press hides the tooltip and crosshair when the finger lifts.
- Annotation label font and screenshot fidelity fixes from 0.5.6 to 0.5.8 are included in this line.

## Stability promise

Stable API follows semver: breaking changes only in a major release, with deprecations lasting at least one minor release and six months. `@experimental` items (the plugin `unstable` surface, `CustomAxisScale`, dataset fast-path interfaces, `blazeplot/plugins/flamegraph`) may change in a minor release. Supported browsers: Chrome and Edge 93+, Firefox 92+, Safari 15.4+.
