# BlazePlot v0.5.7

## Fixes

- `chart.screenshot()` could capture a blank plot (axes, grid and labels but no traces). The frame was rendered before the screenshot module finished loading, so the browser could present a frame and clear the non-preserved WebGL drawing buffer before it was read. The module now loads first and the frame is rendered synchronously right before it is composed. This affected the Screenshot button in the Live performance demo.
