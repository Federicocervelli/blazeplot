# BlazePlot v0.5.4

## Changes

- The crosshair plugin now highlights a hovered bar or histogram bin by brightening it in place instead of drawing an outlined box (#86). The old box had a 2px minimum width, a border, and a dark shadow, so on dense charts where a bin is narrower than a pixel it covered dozens of neighbouring bins. The new highlight covers the bin's exact X interval (at least one CSS pixel wide), has no border or shadow, and looks the same at every zoom level. `markerStrokeColor` sets the highlight color; `markerStrokeWidth` now only applies to point markers.
- Redesigned the website, docs, and demos (#85): a consistent visual identity, a docs layout with sidebar navigation, an on-page outline, and previous/next links, and a demo gallery with source links. Previews are now called demos; existing `/previews` URLs still work.

## Maintenance

- Declarations are now emitted with `tsc` instead of `vite-plugin-dts`, and the project builds with TypeScript 7.
- Switched to trunk-based branching on `main`, updated CI actions and Dependabot configuration, and bumped dev dependencies.
