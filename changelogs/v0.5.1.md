# BlazePlot v0.5.1

## Changes

- Republishes 0.5.0 with its build output. The 0.5.0 tarball on npm was missing `dist/` because the release job packed the package without building it; the release workflow now builds before packing and refuses to publish a tarball without `dist/index.js`.

See [v0.5.0](./v0.5.0.md) for the release notes and [migration guide](../docs/versioning-and-migration.md#migrating-to-05).
