# BlazePlot v1.0.0-rc.8

Eighth 1.0 release candidate. Mobile fixes, a full documentation audit against the current source, and two behavior fixes. Install with `npm install blazeplot@rc`.

## Fixes

- Touch long press: the tooltip and crosshair now hide when the finger lifts, the touch is cancelled, or a second finger lands.
- Y-only gestures (Y-axis drag, `axis: "y"` zoom, wheel over the Y axis) no longer pause latest-X follow or emit `followxchange`. X and both-axis gestures still pause it.
- `downloadBlob`, `isWebGL2Available()` and `sharedRenderer()` no longer use the global `document`: they take an optional document, and the shared renderer keeps one context per document, so they work in iframes and popup windows. The new arguments are additive.
- The live and sensor website demos rendered black on phones (the chart collapsed to its axis height); they now fill their stage.

## Docs

- Every page was audited against the current source and tests. `docs/migrating-to-1.0.md` now covers the event and plugin runtime changes, the title row and axis gutters, and the renderer options (changes 14 to 16, plus a "New in 1.0" section). The built-in plugin, plugin authoring, accessibility, error handling, data semantics, live data, browser support and examples pages were corrected.

## Tooling

- CI is faster: the browser suites run as parallel shards and a normal PR finishes in about 2 minutes (was about 6). Docs-only PRs skip the engine browser suites. The `validate` check still fails if any shard fails.

## Known limitations

- Not yet verified on a physical phone: one-finger page scrolling with `touchPan: "two-finger"` (verified in Chromium's real touch input pipeline).
