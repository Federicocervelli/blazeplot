# BlazePlot v0.5.8

## Fixes

- Annotation labels (`text` on lines, bands and points) now use the chart font. They set `font` as an SVG attribute, which browsers ignore, so labels rendered in the default serif face.
- `chart.screenshot()` is much closer to the live chart: SVG annotation text is drawn with its computed font, fill, anchor and halo; legend items (buttons and spans) are no longer dropped; text is walked per text node with the font computed in the element's own window; legend and navigator backgrounds and borders are painted; and a font whose `font` shorthand is empty (Firefox) falls back to its longhands.
