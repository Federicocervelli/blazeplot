# BlazePlot v1.0.1

A patch release with quick performance wins on the paths where 1.0 still trailed uPlot (hover, chart construction and disposal) and three usability fixes. No breaking changes; one new additive plugin-context method.

## Usability

- **A new chart shows its data.** Until you set a viewport (`setViewport`, `fitToData`, `followX`, pan, zoom, `autoFitY`), the chart fits the visible series on every render, so `chart.addLine({ x, y }); chart.start()` draws the data instead of an empty `0..1` camera, and a streaming chart shows samples as they arrive. The first explicit viewport ends the automatic fit for good. `fitToData()` in the quick start is now optional.
- **Tooltip and crosshair labels follow the X axis.** On a `scale: "time"` axis the default readout is a full timestamp (`2026-10-06 14:03:15`, with milliseconds when present, honoring `timezone` and a string `tickFormat`); on a categorical axis it is the category name. Linear and log values keep the compact 6-significant-digit format. Plugins get the same through the new `ctx.coords.formatReadout(value, axis, yAxis?)`, which returns `null` for numeric axes.
- **Development warning for an off-data viewport.** When the first frame has data but the caller's viewport contains none of it, the console says so once, with both ranges formatted like the axis.

## Performance

- **Hover.** The crosshair no longer forces a synchronous layout on every pointer move: it reads the pointer's plot position from the event, converts with the chart's cached plot size (new `ctx.coords.plotToData`), and caches its label size with a `ResizeObserver`. `nearest-x` picks search the winning series once instead of twice, binary searches over typed-array datasets run without a per-call closure, and the tooltip, crosshair, and pick markers skip DOM writes whose value did not change.
- **Construction and disposal.** The chart stylesheet is injected once per document (or shadow root) instead of once per chart, the `forced-colors` media query is shared per window, one `ResizeObserver` per window serves every chart, a warm plot canvas (mount/destroy cycles) skips the pre-sizing layout read, and the accessibility summary builds its message table once per chart.
- **Per frame.** Axis labels are formatted only when their value or the tick step changes, latest-X follow no longer copies the series array each frame, the Canvas 2D engine caches CSS color strings and skips unchanged `fillStyle`/`strokeStyle`/`lineWidth` writes, and the WebGL2 renderer reuses its command array across frames.

## Internal

- The website deploys from `main` on every push, independent of library releases; links to the former `/next/` site redirect to the root.
- The `v1` branch and the `rc` npm channel are retired; `main` is the only release line.
