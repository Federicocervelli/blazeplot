# BlazePlot v0.5.6

## Fixes

- The Live performance and Sensor stream demos on the website no longer collapse to an axis-height strip on phones and narrow windows. The chart rendered black (and a screenshot export came out as just the axis row) because its container had no definite height; the chart now fills its stage.
- The sensor demo's hover labels show times (#94).

## Tooling

- Added an Oxlint lint step (#95), coverage reporting with ratcheting floors (#96), seeded property tests for data correctness (#99), and Chart lifecycle tests with a fake GPU backend (#100).
- `main` no longer publishes prerelease versions to the `latest` npm tag (#124).
