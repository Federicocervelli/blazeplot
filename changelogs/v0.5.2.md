# BlazePlot v0.5.2

## Changes

- Fixed `series.markDirty()` leaving `StaticDataset` min/max summaries stale after the arrays were mutated in place, which produced wrong dense rendering and `fitToData` extents (regression in 0.5.0). Datasets can now implement an optional `invalidate()` hook that `markDirty()` calls.
- `series.replace({ x?, y })` now works for `StaticDataset`, swapping the arrays without copying them. Use it to redraw a whole signal (a spectrum or waveform) on one series instead of removing and re-adding it. `x` is optional, so a fixed X axis is not resent.
- Docs: new "Replacing a whole signal" section in the live data guide.
- `bun run release <patch|minor|major>` replaces the `version:*` scripts and drafts the changelog from commits.
- Browser test scripts no longer leave a Vite server running after a failure and detect Chrome, Brave, and Edge on Windows.
